# Product Vision

Atellier Studio is a private local-first AI operating system for personal and mini-agency work.

It turns daily context into a durable loop:

source/input -> wiki update -> task -> agent run -> review -> deliverable -> memory update

The product should feel like a serious internal workspace. It is not a public SaaS MVP, a game, or a generic task manager.

## Principles

- Keep operational memory human-readable.
- Preserve raw sources.
- Promote reusable knowledge into the wiki.
- Keep MongoDB focused on operational state.
- Require human review for important external actions.
