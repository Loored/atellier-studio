# Memory Artifact Hygiene

**Date:** 2026-05-12
**Status:** Active policy for local memory curation.

## Goal

Keep Atellier's durable memory readable while preserving useful operational evidence.

Atellier should track curated knowledge and human-readable run history. It should not make every generated deliverable from smoke tests and validation loops part of the publishable knowledge base.

## Track by default

- `atelier/raw/**`: immutable source inputs.
- `atelier/wiki/log.md`: chronological operational memory.
- `atelier/wiki/index.md`: curated memory index.
- `atelier/wiki/sources/**`: source summaries.
- `atelier/wiki/synthesis/**`: reviewed/captured synthesis pages.
- `atelier/wiki/workflows/**`: workflow memory.
- `atelier/wiki/dreams/**`: explicitly approved dream reports.
- `atelier/tasks/**`: task views and triage.
- `atelier/runs/YYYY-MM-DD-meaningful-name.md`: human-readable implementation and decision run logs.
- `docs/**`: product, architecture, operation, and planning docs.

## Ignore by default

- `atelier/wiki/deliverables/<24hex>-*.md`
- `atelier/wiki/deliverables/<uuid>-*.md`
- `atelier/runs/YYYY-MM-DD-codex-worker-<uuid>.md`
- `atelier/runs/artifacts/*.stdout.log`
- `atelier/runs/artifacts/*.stderr.log`

These files are useful local evidence, but they are usually generated by smoke tests, manual validation, or repeated orchestration runs. The curated record should live in the wiki log, source/synthesis pages, durable run logs, and reviewed deliverable indexes.

## Curating generated deliverables

When a generated deliverable contains durable knowledge:

1. Summarize or promote the useful content into a curated wiki page under `sources`, `synthesis`, `workflows`, `decisions`, or `dreams`.
2. Add or update an entry in `atelier/wiki/index.md`.
3. Add a concise event to `atelier/wiki/log.md`.
4. Keep the raw generated deliverable local unless there is a clear reason to preserve the full file.

## Curating Codex Worker evidence

Generated Codex Worker finalize logs are local evidence by default. When a run reflects a meaningful product decision or implementation milestone, write a narrative run log with a stable filename such as `atelier/runs/2026-05-12-knowledge-graph-direction.md` and link it from `atelier/wiki/log.md`.

## Knowledge Graph implication

The Knowledge Graph should read from curated memory first. It may optionally include ignored generated artifacts when running locally, but the default product graph should avoid treating unreviewed generated files as durable knowledge.
